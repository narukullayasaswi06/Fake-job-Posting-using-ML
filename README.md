A Machine Learning project that detects fake job postings using NLP and classification algorithms. The system analyzes job descriptions and predicts whether a job advertisement is genuine or fraudulent.

Tech Stack
-Python
-Machine Learning
-NLP
-Scikit-learn
-Pandas & NumPy

Features
-Fake job detection
-Text preprocessing
-Model training & prediction
-Accuracy evaluation

Algorithms Used
-Logistic Regression
-Naive Bayes
-Random Forest

Dataset
Public fake job posting dataset from Kaggle
